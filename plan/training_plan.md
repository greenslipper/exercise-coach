## Weekly template

Flexible — Mon/Wed/Fri are the best gym days, Tue/Thu good, Sat worst, Sun ok. Move sessions around tennis and life using the loading rules below.

| Day | Session |
|-----|---------|
| Mon | Gym legs A (Ankle & Hips) + elbow |
| Tue | Home iso + elbow |
| Wed | Easy run w/ plyo warm-up + elbow *(→ speed 4×1km from Week 6)* |
| Thu | Gym legs B (Ankle & Hips) + elbow |
| Fri | Home iso + elbow |
| Sat | Rest / tennis + elbow |
| Sun | Long run w/ plyo warm-up + elbow |

**Fast-twitch placement (per Yasmin):** the home plyos are done as a **warm-up on run days** (Wed + Sun), not as standalone sessions. That's 2× fast-twitch/week attached to runs, which potentiates the run and keeps standalone calf load off the rest of the week. Tue/Fri are therefore iso + elbow only.

### Loading rules (the calf is the governor)
1. Keep the two gym leg days ≥48h apart.
2. Plyos live as the run-day warm-up — a short primer, not a full session before the long run.
3. Keep the day before the long run light (rest/tennis, not gym).
4. **Tennis counts as calf + fast-twitch load** — if you play, keep the following day easy.
5. Calf grumbles → cut in this order: **plyo warm-up → easy run → long-run distance**. Protect the gym strength and iso work; those are what fix the problem.
6. Elbow set is daily regardless — it's light.

### Home iso (Tue + Fri) — from Yasmin's program

### Fast-twitch / plyos (run-day warm-up, Wed + Sun) — from Yasmin's program

### Elbow (daily) — golfer's elbow rehab, from Yasmin's program
Wrist flexion (dumbbell) · wrist extension (with weight) · forearm supination/pronation (with weight) — ~1–2 × 15 each, slow, pain ≤3/10. Plus ibuprofen gel for the first 2 weeks.

Resume full upper-body strength (rotator cuff, face pulls, chest, shoulder press, rows, core) once the elbow is cleared. Reintroduce gradually and keep it off heavy-leg days.
